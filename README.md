# Jahanavi_chatbot
 A Python-based chatbot designed to provide an interactive and user-friendly conversational experience. It features automated responses, a customizable interface, and a simple design. This project showcases Python programming skills and explores the development of intelligent chatbot applications.
# Key Features:
 Interactive chatbot interface
 Automated responses to user queries
 User-friendly design
 Python-based implementation
# Technologies Used: Python and relevant libraries used in the project.
# Purpose: To develop practical programming skills and explore chatbot development as part of learning software engineering.
